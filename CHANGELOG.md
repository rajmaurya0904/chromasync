# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v0.1.0.html).

## [0.1.0] - 2025-02-25

### Added
- Initial release of Chromasync CLI tool.
- Bidirectional synchronization between local color design tokens (Tailwind, CSS variables, Style Dictionary) and Figma variables via API.
- Zero-config setup and detection of local token files and configuration.
- Comprehensive test suite and CI workflow.
